# Especificação: US-007 - Editar Perfil

## Objetivo
Como usuário, quero editar meu perfil para manter minhas informações atualizadas.

## Critérios de Aceite (Requisitos)
- O usuário deve poder alterar nome e avatar.
- As alterações devem ser salvas imediatamente.
- O perfil atualizado deve ser exibido na seleção de perfis (salvo no localStorage).
