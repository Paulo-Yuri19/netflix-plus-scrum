# Especificação: US-008 - Excluir Perfil

## Objetivo
Como assinante, quero excluir um perfil que não seja mais utilizado para manter minha conta organizada.

## Critérios de Aceite (Requisitos)
- O assinante deve poder selecionar um perfil para exclusão.
- O sistema deve solicitar uma confirmação antes de excluir de fato.
- O perfil deve ser removido da lista de perfis.
