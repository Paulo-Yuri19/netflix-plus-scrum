# Especificação: US-010 - Alterar Avatar

## Objetivo
Como usuário, quero alterar o avatar do meu perfil para personalizá-lo.

## Critérios de Aceite (Requisitos)
- O usuário deve visualizar uma lista de avatares disponíveis.
- O avatar selecionado deve ser salvo.
- O novo avatar deve aparecer na tela de seleção de perfis.
