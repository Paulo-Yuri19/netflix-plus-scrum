# Product Vision – Netflix+

## Visão do Produto

A Netflix+ é uma plataforma de streaming de filmes e séries que permite aos usuários assistir conteúdos sob demanda, criar perfis personalizados e gerenciar sua assinatura de forma simples e intuitiva.

## Objetivo

Desenvolver uma plataforma moderna de streaming que ofereça uma experiência personalizada, segura e acessível aos usuários.

## Público-Alvo

- Jovens
- Adultos
- Famílias
- Crianças (perfil infantil)

## Principais Funcionalidades

- Cadastro e Login
- Gerenciamento de Perfis
- Catálogo de Filmes e Séries
- Reprodução de Conteúdo
- Gerenciamento de Assinatura
- Administração do Catálogo

## Benefícios

- Interface intuitiva.
- Recomendações personalizadas.
- Reprodução em diferentes dispositivos.
- Facilidade no gerenciamento da conta.

## MVP (Produto Mínimo Viável)

As funcionalidades previstas para o MVP são:

- Cadastro de usuário
- Login
- Criar perfil
- Pesquisar conteúdo
- Visualizar detalhes
- Assistir conteúdo
