# Sprint 0

## Objetivo

Preparar o ambiente de desenvolvimento e organizar o projeto utilizando a metodologia Scrum.

## Atividades

- Definição da equipe.
- Escolha do Scrum Master.
- Escolha do Product Owner.
- Definição do sistema Netflix+.
- Elaboração da Product Vision.
- Criação do Product Backlog.
- Configuração do repositório GitHub.
- Configuração do GitHub Project.
- Criação das Labels.
- Criação das Milestones.
- Cadastro das User Stories.

## Resultado Esperado

Ao final da Sprint 0, o projeto estará completamente planejado e organizado para iniciar o desenvolvimento.
